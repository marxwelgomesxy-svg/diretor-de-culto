# Instalação pelo GitHub

1. Substitua os arquivos do repositório pela estrutura desta versão.
2. Confirme que `.github/workflows/build.yml` está em `.github/workflows/`.
3. Vá em Actions → Build Diretor de Culto - OBS 27.2.4.
4. Clique em Run workflow.
5. Ao terminar com sucesso, baixe o artifact `Diretor-de-Culto-OBS27.2.4-Windows-x64`.

O build usa as fontes e o runtime oficiais do OBS Studio 27.2.4 e Qt5, portanto o objetivo desta versão é compatibilidade específica com OBS 27.2.4.
