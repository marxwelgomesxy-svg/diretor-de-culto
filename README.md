# Diretor de Culto — OBS Studio 27.2.4

Plugin nativo C++/Qt5 para OBS Studio 27.2.4 (Windows x64).

Não usa Lua, Python ou scripts externos.

A versão atual implementa o dock nativo, leitura da cena atual, modos Manual/Assistido/Automático, sugestões baseadas somente no estado real das cenas, cortes reais e suporte a Studio Mode.

O motor de visão/áudio ainda não está ativo nesta fase e não é simulado.
